# Personal Projects

A collection of personal projects, experiments, scripts, utilities, and proof-of-concepts built while exploring different technologies.

## Overview

This repository contains projects that don't necessarily belong to a single technology or platform.

It serves as a workspace for building, testing, experimenting, and learning through practical projects.

## Areas Covered

Projects may include:

- Cybersecurity
- Linux
- Networking
- Automation
- Python
- PowerShell
- Bash
- Cloud
- APIs
- System administration
- DevOps
- Infrastructure
- Security tooling

## Projects

Each project is designed to solve a specific problem, automate a task, explore a technology, or demonstrate a technical concept.

Projects may range from small scripts and utilities to larger experiments involving multiple technologies.

## Philosophy

> Build it. Break it. Understand it. Improve it.

The purpose of this repository is not only to store finished projects but also to document experiments, failures, troubleshooting, and lessons learned.

## Disclaimer

Some projects are experimental or intended for educational purposes. Review and test code in a controlled environment before using it in production.
